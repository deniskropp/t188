# How does this compare to traditional AI text generation models?

-   **Traditional Models**: Operate on an Input -> Black Box -> Output loops. This is comparable to an **"Improv Actor"** style, where the AI makes up the story as it goes.
-   **Theatrical Director's Model**: Operates on an Input -> Rehearsal (Plan) -> Critique -> Performance loop. This is a **"Scripted/Directed"** style, where the AI prepares a mental model and gets approval before performing.
